# Othello Game

Welcome to my Othello project! 🎮

## About
This project is a C++ implementation of the classic strategy board game, Othello (also known as Reversi). It was developed during my **first semester at university** as a fundamental programming project. 

The goal of this project was to understand game logic, board state management, and algorithmic thinking using C++. It represents my first steps into the world of software engineering, and I’m proud to share this early milestone of my coding journey here.
